API Reference

Complete reference for all Formation API endpoints. Base URL: https://api.formation.dev/api/v1

Interactive docs: For a live, interactive API explorer, visit /docs (Swagger UI) or /redoc (ReDoc).

Authentication

MethodEndpointDescription
POST/auth/registerCreate a new user account
POST/auth/loginLogin with email/password, returns JWT
GET/auth/meGet current user profile
PATCH/auth/meUpdate user profile
GET/auth/scopesList all available API key scopes
POST/auth/api-keysCreate a new API key
GET/auth/api-keysList all API keys
PATCH/auth/api-keys/{id}Update API key settings
POST/auth/api-keys/{id}/renewExtend key expiration
POST/auth/api-keys/{id}/rollRotate key (new key, same settings)
DELETE/auth/api-keys/{id}Revoke an API key

Formation Orders

MethodEndpointDescription
POST/ordersCreate a new formation order
GET/ordersList orders (filterable by status)
GET/orders/{id}Get order details
PATCH/orders/{id}Update a draft order
POST/orders/{id}/membersAdd member/officer to order
DELETE/orders/{id}/members/{mid}Remove member from order
POST/orders/pricingGet pricing estimate (no auth)
POST/orders/name-checkCheck business name availability

Create Order Request Body

{
  "entity_type": "llc",                        // Required: llc, corporation, s_corp, nonprofit, lp, llp
  "state_of_formation": "DE",                  // Required: 2-letter state code
  "business_name": "Acme LLC",                 // Required: must meet state naming rules
  "business_name_alt1": "Acme Ventures LLC",   // Optional: backup name
  "business_name_alt2": "Acme Tech LLC",       // Optional: second backup
  "business_purpose": "Technology consulting",  // Optional: business purpose
  "business_address_line1": "123 Main St",     // Required
  "business_city": "Wilmington",               // Required
  "business_state": "DE",                      // Required
  "business_zip": "19801",                     // Required
  "processing_speed": "standard",              // standard, expedited, rush
  "include_registered_agent": true,
  "include_ein": false,
  "include_operating_agreement": false,
  "members": [{
    "role": "owner",
    "full_name": "Jane Doe",
    "email": "jane@example.com",
    "ownership_percentage": 100,
    "address_line1": "456 Oak Ave",
    "city": "San Francisco",
    "state": "CA",
    "zip_code": "94105"
  }]
}

Error Responses

All errors follow a consistent format:

{
  "detail": "Human-readable error message"
}

// 400 - Bad Request (validation error)

// 403 - Forbidden (insufficient permissions)
// 404 - Not Found
// 429 - Rate Limit Exceeded
// 500 - Internal Server Error
