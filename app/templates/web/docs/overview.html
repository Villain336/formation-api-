How It Works

The Formation API follows a straightforward workflow:

  1. Check state requirements — Query the states endpoint to get filing fees, processing times, and requirements for a specific state and entity type.
  2. Check name availability — Verify the business name meets state naming rules and isn't restricted.
  3. Create a formation order — Submit the business details, members/officers, and desired options.
  4. Process payment — Create a Stripe payment intent and process the state filing fee + service fee.
  5. Track the order — Monitor order status via API polling or webhook notifications as it moves through: draft → paid → processing → filed → completed.
  6. Download documents — Retrieve generated and filed documents (Articles, Operating Agreement, EIN confirmation).
  7. Manage compliance — Track upcoming compliance deadlines (annual reports, franchise taxes, etc.).

Authentication Methods

The API supports two authentication methods:

1. JWT Bearer Token (for user-facing apps)

curl -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..." \
     https://api.formation.dev/api/v1/orders

2. API Key (for server-to-server)

curl -H "X-API-Key: form_live_sk_a1b2c3d4..." \
     https://api.formation.dev/api/v1/orders

See the Authentication guide for detailed setup instructions.
