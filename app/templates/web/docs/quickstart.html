Quickstart Guide

This guide walks you through creating your first business formation order in under 5 minutes.

Step 1: Create an Account

curl -X POST https://api.formation.dev/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "developer@example.com",
    "password": "secure-password-here",
    "full_name": "Jane Developer",
    "company_name": "Acme Platforms Inc"
  }'

You'll receive a JWT access token and your user profile in the response. Save the access_token.

Step 2: Create an API Key

API keys are recommended for server-to-server communication. They support scopes, rate limits, and environment separation.

curl -X POST https://api.formation.dev/api/v1/auth/api-keys \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Development Key",
    "environment": "test",
    "scopes": ["orders:read", "orders:write", "states:read"]
  }'
Important: The full API key is only shown once at creation time. Copy and store it securely. You will not be able to retrieve it later.

Step 3: Check State Requirements

Before creating an order, check the requirements for your desired state and entity type:

curl https://api.formation.dev/api/v1/states/DE/llc \
  -H "X-API-Key: form_test_sk_..."

Response includes filing fees, processing times, naming rules, and required documents.

Step 4: Check Name Availability

curl -X POST https://api.formation.dev/api/v1/orders/name-check \
  -H "X-API-Key: form_test_sk_..." \
  -H "Content-Type: application/json" \
  -d '{
    "business_name": "Acme Ventures LLC",
    "state": "DE",
    "entity_type": "llc"
  }'

Step 5: Create a Formation Order

curl -X POST https://api.formation.dev/api/v1/orders \
  -H "X-API-Key: form_test_sk_..." \
  -H "Content-Type: application/json" \
  -d '{
    "entity_type": "llc",
    "state_of_formation": "DE",
    "business_name": "Acme Ventures LLC",
    "business_purpose": "Technology consulting and software development",
    "business_address_line1": "123 Innovation Way",
    "business_city": "Wilmington",
    "business_state": "DE",
    "business_zip": "19801",
    "processing_speed": "standard",
    "include_registered_agent": true,
    "include_ein": true,
    "include_operating_agreement": true,
    "members": [
      {
        "role": "owner",
        "full_name": "Jane Doe",
        "email": "jane@acmeventures.com",
        "ownership_percentage": 100,
        "address_line1": "456 Main St",
        "city": "San Francisco",
        "state": "CA",
        "zip_code": "94105"
      }
    ]
  }'

The order is created in draft status. The response includes the calculated pricing breakdown.

Step 6: Process Payment

curl -X POST https://api.formation.dev/api/v1/payments/create-intent \
  -H "X-API-Key: form_test_sk_..." \
  -H "Content-Type: application/json" \
  -d '{"order_id": "ORDER_ID_FROM_STEP_5"}'

You'll receive a Stripe client_secret to complete payment on the frontend using Stripe.js.

Step 7: Track Order Status

Poll the order endpoint or set up webhooks:

curl https://api.formation.dev/api/v1/orders/ORDER_ID \
  -H "X-API-Key: form_test_sk_..."

Order Status Flow

draft → pending_payment → paid → processing → filed → completed
                                     ↓
                                  rejected → processing (retry)
