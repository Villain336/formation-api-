Use Case

Fintech: One-Click Business Account

A neobank wants to let users form an LLC and open a business bank account in a single onboarding flow. The user enters their info once, and your platform handles formation, EIN, and account setup.

The User Sees

  1. User enters name, address, business name on your signup page
  2. User picks LLC type and state (default: Wyoming for low fees)
  3. User pays a single fee (your markup + state fee)
  4. Your backend creates the order via Formation API
  5. User gets updates: "LLC filed", "EIN received", "Account ready"
  6. Business bank account is opened using the EIN and filed documents

What Happens Behind the Scenes

Your server makes 3 API calls: create order, process payment, set up webhook. Formation API handles the rest — filing, EIN, registered agent, document generation, and compliance tracking.

your-backend/onboarding.py
import httpx

FORMATION_API = "https://api.formation.dev/api/v1"
API_KEY = "form_live_sk_..."
HEADERS = {"X-API-Key": API_KEY}

async def onboard_business_customer(user_data):
    # Step 1: Create formation order
    order = httpx.post(
        f"{FORMATION_API}/orders",
        headers=HEADERS,
        json={
            "entity_type": "llc",
            "state_of_formation": "WY",
            "business_name": user_data["business_name"],
            "business_address_line1": user_data["address"],
            "business_city": user_data["city"],
            "business_state": user_data["state"],
            "business_zip": user_data["zip"],
            "include_registered_agent": True,
            "include_ein": True,
            "members": [{
                "role": "owner",
                "full_name": user_data["name"],
                "email": user_data["email"],
                "ownership_percentage": 100,
                "address_line1": user_data["address"],
                "city": user_data["city"],
                "state": user_data["state"],
                "zip_code": user_data["zip"],
            }],
        },
    ).json()

    # Step 2: Create payment intent
    payment = httpx.post(
        f"{FORMATION_API}/payments/create-intent",
        headers=HEADERS,
        json={"order_id": order["id"]},
    ).json()

    # Step 3: Return to your frontend
    return {
        "order_id": order["id"],
        "total": order["total_amount"],
        "stripe_secret": payment["client_secret"],
    }

Use Case

Multi-Member LLC with Custom Ownership

A legal tech platform helps business partners form an LLC together. Two members with different ownership splits, one designated as managing member.

The User Sees

  1. Form asks "How many owners?" and collects each person's info
  2. Users set ownership percentages (must total 100%)
  3. One member is designated as the managing member
  4. Operating agreement is auto-generated with the ownership split
  5. Both members receive copies of all documents

What Gets Generated

  • Certificate of Formation (filed with Delaware)
  • Operating Agreement with 60/40 ownership split
  • EIN confirmation letter from the IRS
  • Registered agent designation
Tip: The include_operating_agreement: true flag auto-generates a state-compliant operating agreement using the member data you provide. It includes the ownership percentages, management structure, and dissolution terms.

your-backend/webhook_handler.py
from fastapi import Request
import hmac, hashlib

WEBHOOK_SECRET = "whsec_a1b2c3d4e5f6..."

@app.post("/webhooks/formation")
async def handle_webhook(request: Request):
    body = await request.body()
    sig = request.headers["X-Formation-Signature"]

    # Verify signature
    expected = hmac.new(
        WEBHOOK_SECRET.encode(),
        body, hashlib.sha256
    ).hexdigest()
    if sig != expected:
        return {"error": "Invalid signature"}

    event = await request.json()

    if event["type"] == "order.completed":
        order_id = event["data"]["order_id"]
        # Notify your user, open bank account, etc.
        send_email(order_id, "Your LLC is ready!")

    if event["type"] == "ein.received":
        ein = event["data"]["ein_number"]
        # Auto-open bank account with EIN
        open_bank_account(ein)

    return {"received": True}

An accelerator forms Delaware C-Corps for every company in their cohort. Expedited processing to get entities ready before Demo Day.

Why Delaware C-Corp?

International Founder: US Entity from Abroad

An immigration services platform helps non-US founders form US entities. The registered agent is critical here — the founder has no US address.

What the International User Needs

  • Registered agent — required legal address in the formation state
  • EIN — needed for US bank account and tax filings
  • Operating agreement — proves ownership structure
  • Certificate of formation — proof the entity exists

Why Wyoming?

No state income tax, low filing fees ($100), strong privacy protections (no public member disclosure), and simple annual report ($60). This is the #1 choice for non-US founders forming LLCs.

Compliance note: Non-US founders still need an ITIN or SSN for the responsible party on the EIN application. The Formation API's EIN service handles this workflow, including SS-4 form preparation.

Use Case

Accounting Platform: Compliance Dashboard

An accounting SaaS pulls compliance data from Formation API to show their users upcoming deadlines — annual reports, franchise taxes, and FinCEN BOI reports.

Auto-Created Compliance Tasks

When a formation order completes, Formation API automatically creates all relevant compliance tasks based on the state and entity type:

  • Annual Reports — due dates vary by state (some by anniversary, some by calendar)
  • Franchise Tax — Delaware ($300 LLC), California ($800 minimum), etc.
  • Publication — New York requires 6-week newspaper publication
  • BOI Report — FinCEN Beneficial Ownership report (90 days after formation)

Your Dashboard Shows

Pull the /compliance endpoint and display upcoming deadlines. Filter by status: upcoming, due, overdue, filed.
