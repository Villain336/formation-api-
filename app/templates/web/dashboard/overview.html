Quick Start

Get started with the Formation API in 3 steps:

  1. Create an API key — Go to API Keys and create a test key.
  2. Make your first API call — Use the key to query state requirements: 
    curl https://api.formation.dev/api/v1/states/DE/llc \
  -H "X-API-Key: YOUR_TEST_KEY"
  3. Create a test order — Submit a formation order in test mode. See the Quickstart Guide.
